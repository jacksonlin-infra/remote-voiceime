# 支持范围与已知限制

当前发布：**macOS 0.3.0 alpha（构建 10）**、**Windows 0.3.1 alpha（构建 11）**。两端独立发布，版本号不必相同。返回[项目首页](../README.md)。

## 已验证的使用链路

| 本地电脑 → 远控软件 → 远端 | 状态 |
| --- | --- |
| macOS → UU 远程 → macOS / Windows | 日常流程已验证 |
| macOS → 微软 Windows App → Windows | 日常流程已验证 |
| Windows → UU 远程 → macOS / Windows | 日常流程已验证（三次按键） |
| Windows → 远程桌面连接（mstsc）→ Windows | 日常流程已验证（三次按键） |

“日常流程”指：在普通窗口中听写、自动投送、再贴一次和核对后投送。语音识别依赖本机豆包输入法；豆包或远控软件升级后行为可能变化，遇到问题请按[反馈方式](../CONTRIBUTING.md#问题反馈)提交环境信息。

以下场景尚未形成完整验证，可能可用，但不作保证：

- 全屏远控窗口、多显示器、真实 125% / 150% / 200% 高 DPI；
- Deskflow / Synergy 等键鼠与剪贴板共享工具同时运行；
- Intel Mac、低于 macOS 13 的系统、Windows ARM；
- 其他版本的豆包输入法、UU 远程或 Windows App。

## 系统要求

| 平台 | 要求 |
| --- | --- |
| macOS | macOS 13 及以上；当前发行包仅 Apple Silicon（arm64） |
| Windows | Windows 10 / 11 x64；安装包已内置 .NET 运行时 |

两端都只需安装在**你操作键盘和麦克风的本地电脑**，远端无需安装。

## 已知限制

1. **投送没有回执。** “已投送”只表示本机已发出粘贴按键，工具无法读取远端是否收到；不会自动重发，以免重复输入。没出现时先看一眼远端，再用“再贴一次”或最近文字。
2. **依赖剪贴板同步。** 文字通过远控软件的“本地 → 远端”剪贴板同步整段粘贴。同步慢于粘贴时可能贴出旧内容，可在设置中改为“兼容”同步速度。
3. **无法识别远端输入框。** 投送目标是原远控窗口；听写期间请保持远端光标位置。同一窗口内多个远端会话之间不做隔离。
4. **签名。** macOS 使用临时（ad-hoc）签名、未公证，升级后可能需要重新关联辅助功能和输入监控；Windows 暂无发布者签名，首次运行可能出现 SmartScreen 提示。
5. **配置粒度。** Windows 按 UU 设备记住粘贴键；macOS 目前按远控客户端保存，尚未区分同一客户端下的不同设备。
6. **Windows 不提供长按重贴。** 与豆包共用右 Ctrl 时无法可靠区分长按，请使用提示上的“再贴一次”或托盘菜单。

## 当前不提供

- 按住说话、逐字实时输入到远端；
- 豆包以外的语音来源、上表以外的远控软件；
- Linux 客户端、远端接收程序。

这些方向欢迎在 Issues 中讨论使用场景，但目前没有承诺的发布时间。

## 数据与隐私

- 本工具不录音、不调用识别 API、不联网，也不把听写正文写入磁盘或日志。识别由豆包完成；豆包和远控软件有各自的数据处理方式。
- 听写文字暂存在内存和剪贴板中，默认投送后留在剪贴板；可在“设置 → 通用”改为投送后恢复原内容。
- 最近文字只在内存中保留 5 条、5 分钟，退出即清空。
- 诊断信息只含阶段、检查结果、按键与耗时等元数据，不含正文、剪贴板内容或窗口标题。
