# Remote VoiceIME 0.2.1 · macOS alpha

构建 9，2026-10-19。将本地豆包听写的文字通过 UU / Windows App 的剪贴板同步投送到远端输入框。本次发布仅包含 **macOS arm64**，Windows 当前发布仍为 0.2.0。

## 本版变化

- macOS 工具键统一为**右 Ctrl**：开始、结束听写及核对投送使用同一键；右 Alt 不再由工具接管。
- 单独轻按才触发；Ctrl 组合键、Ctrl＋点击、滚轮及拖动保留原操作，焦点变化或监听中断取消当前触发。
- 构建 9 补齐听写按钮残留的 Option 符号；与用户验收的构建 8 相比只修改两处显示文字，不改变触发或投送逻辑。
- 统一浮条、设置、首次校准和最近文字中的按键提示。
- 更新产品首页、当前进展、使用说明和原生界面截图，明确当前功能与历史规划的区别。
- 增加独立 macOS 打包脚本，核对版本、源码摘要、签名、架构及 ZIP 内容。

原有豆包菜单启动、Return 结束、定稿判断和剪贴板投送流程保持。Mac 版不要求修改豆包自身的语音快捷键。

## 下载与安装

下载 `RemoteVoiceIME-0.2.1-macos-arm64.zip`；校验文件为 `SHA256SUMS.macos-arm64.txt`。

```bash
shasum -a 256 -c SHA256SUMS.macos-arm64.txt
```

1. 从菜单栏退出旧版，将解压后的 `Remote VoiceIME.app` 放入 `/Applications` 等固定位置，再打开这一份。
2. 菜单或“关于与数据”应显示 **0.2.1（构建 9）**。
3. 确认辅助功能、输入监控有效；显示“已就绪”后，在 UU 远端输入框按右 Ctrl 开始，再按一次结束并投送。

最低部署目标为 macOS 13，此次仅发行 Apple Silicon 包。应用使用 ad-hoc 临时签名，**未做 Developer ID 签名或公证**；升级后可能需要在系统设置重新关联这两项权限并重开。工具自身不申请麦克风或屏幕录制权限。

## 验证范围

- 用户确认 0.2.1 构建 8 基本功能无明显问题，UU → macOS / Windows 均有成功反馈。
- 160 项 macOS 隔离逻辑检查通过，覆盖右 Ctrl、组合键、焦点变化、定稿、队列、恢复及按键取消；当前 AppKit 原生预览检查通过。
- 6 项原生命名剪贴板检查在 0.2.0 通过；本版剪贴板后端未改动。构建 9 已重新构建并验证，功能逻辑沿用构建 8；最终发行构建的真实远控流程未另行复测。
- Windows App → Windows 在前版有实测记录，0.2.1 右 Ctrl 版仍待单独回归；Deskflow、全屏、多屏等不在本次基本验收结论内。

## 已知限制

- UU → Windows 曾出现一次首次未收到、随后恢复的情况，尚无失败诊断支持具体归因。当前仍为固定同步等待，没有远端回执；不宣称该间歇问题已修复。
- “已发出、远端未确认”只证明本机发出了粘贴按键。重发前先核对远端，避免重复输入。
- Mac 按客户端保存粘贴键和速度，尚未按 UU 设备分别保存；请按实际手动粘贴映射校准。
- 本工具不录音、不联网、不落盘保存正文；最近文字仅在内存保留 5 条 / 5 分钟，退出即清空。豆包与远控客户端有各自的数据处理方式。
