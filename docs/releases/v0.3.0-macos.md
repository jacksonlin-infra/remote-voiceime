# Remote VoiceIME 0.3.0 · macOS alpha

构建 10，2026-10-25。将本地豆包听写的文字通过 UU / Windows App 的剪贴板同步投送到远端输入框。本次发布仅包含 **macOS arm64**，Windows 当前发布仍为 0.2.0。

本版针对早期使用中反馈的“语音不出来”“结果没投到远端”“远端一直贴出同一段旧内容、只能手动复制”“快速按键或关闭后容易失灵”“每次启动都进引导、授权重启后从头开始”等问题，重写了投送与取消的处理，并换上新的交互。

## 投送更可靠

- **远端不再反复贴出旧内容。** 同步速度改为快速 180 ms / 标准 0.5 秒 / 兼容 1.2 秒三档，UU 默认标准，久未使用后的第一条至少等 0.8 秒；听写文字默认留在剪贴板，远端没出现时可直接手动粘贴（可在设置中改回恢复原剪贴板）。
- **投送前会等窗口和按键稳定。** 远控窗口回到前台并稳定、修饰键松开后再粘贴，最多多等 1.5 秒，不再到点检查一次就放弃。
- **切回远端窗口适配新版 macOS。** 不再因系统拒绝激活请求而直接判失败；改为让出前台、请求激活并用辅助功能置前，由投送前检查等待窗口真正回到前台。
- **远控回写剪贴板时自动重写。** 窗口获得焦点时远端剪贴板被同步回本机，且你没有键鼠操作时，重新写入一次并重新等待。
- **快速连按不再丢键。** 上一条还在粘贴时按右 Ctrl，粘贴完成后自动开始这一轮。
- **取消只影响本轮。** 之前排队的文字在确认豆包空闲后继续投送；取消后马上开始，豆包仍在录音则直接接入。
- **语音更容易起来。** 等本工具真正到前台再唤起豆包，失败自动重试一次，再失败时按右 Ctrl 重试；按了没说话 2.5 秒后提示并交还焦点。
- **键盘监听移到独立线程**，界面或辅助功能调用卡顿时不再漏键。

## 新的交互

- **胶囊浮条**：听写时一行显示正在听、听到了什么、按什么结束；长文向上展开，最多 8 行最新文字。浮条加宽到 600 pt。
- **每次按键都有回应**：已投送、没识别到、找不到远程窗口、本次未投送等都在屏幕底部提示，不抢焦点。
- **再贴一次**：点“已投送”提示上的按钮、在远端长按右 Ctrl，或从菜单“最近文字”选“再投送到原窗口”，一步重贴。
- **核对后投送**：含换行的文字在卡片中核对，右 Ctrl 投送，不再需要二次勾选；被拒时显示原因。
- **准备清单**替代四步引导：自动检测豆包、权限和远控软件；输入监控可在应用内重开，重开后回到清单，已完成项不再询问；必需项就绪后启动不再弹出。
- **试一次**：在真实远端输入框按右 Ctrl 投送测试文字；没出现时按现象一键改兼容速度或粘贴键后立即重测。结果按客户端保存。
- **菜单精简**为状态、最近文字、暂停、设置、退出；菜单栏图标区分就绪、听写中、投送中、需处理、已暂停。设置合并为通用、远程客户端、权限与诊断三页。
- **诊断**标明投送停在哪一道检查，以及核对卡片被拒的原因代码；仍不含正文、剪贴板内容或窗口标题。

## 下载与安装

下载 `RemoteVoiceIME-0.3.0-macos-arm64.zip`；校验文件为 `SHA256SUMS.macos-arm64.txt`。

```bash
shasum -a 256 -c SHA256SUMS.macos-arm64.txt
```

1. 从菜单栏退出旧版，将解压后的 `Remote VoiceIME.app` 放入 `/Applications` 等固定位置，再打开这一份。
2. 在“设置 → 权限与诊断”底部核对 **0.3.0（构建 10）**。
3. 按准备清单完成必需项。升级后若系统授权失效，清单会标出对应项；输入监控授权后点“重新打开应用”。

最低部署目标为 macOS 13，此次仅发行 Apple Silicon 包。应用使用 ad-hoc 临时签名，**未做 Developer ID 签名或公证**；升级后可能需要重新关联辅助功能与输入监控。工具自身不申请麦克风或屏幕录制权限。

## 验证范围

- 用户在实际使用的远控环境中实测，确认日常听写、再投送与核对后投送正常，使用顺畅。
- 216 项 macOS 隔离逻辑检查、6 项原生命名剪贴板检查及 AppKit 原生预览检查通过。
- Windows App、全屏、多屏、Deskflow 及其他专项未在本次单独回归。

## 已知限制

- 投送没有远端回执：“已投送”表示本机已发出粘贴键。
- 默认投送后听写文字留在剪贴板，需要恢复原剪贴板的请在“设置 → 通用”中修改。
- Mac 按客户端保存粘贴键和速度，尚未按 UU 设备分别保存。
- Windows 端尚未移植本版的投送等待与取消处理。
- 本工具不录音、不联网、不落盘保存正文；最近文字仅在内存保留 5 条 / 5 分钟，退出即清空。
