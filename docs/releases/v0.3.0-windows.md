# Remote VoiceIME 0.3.0 · Windows alpha

构建 10，2026-10-25。将本地豆包听写的文字通过 UU 远程或远程桌面（mstsc）的剪贴板同步投送到远端输入框。本次发布仅包含 **Windows x64**；macOS 当前发布为 [0.3.0](https://github.com/jacksonlin-infra/remote-voiceime/releases/tag/v0.3.0-macos)。

本版把 macOS 0.3.0 的投送可靠性修复与交互改版移植到 Windows，针对“语音不出来”“结果没投到远端”“远端一直贴同一段旧内容”“快速按键或关闭浮条后失灵”“再投送 / 核对后投送没反应”“每次启动都进引导”等问题；并首次提供安装程序。

## 安装程序

- `RemoteVoiceIME-0.3.0-win-x64-setup.exe`：只为当前用户安装，**不需要管理员权限**，不安装服务、不开机自启；开始菜单快捷方式、可选桌面快捷方式，可在“已安装的应用”中卸载，卸载保留设置。
- 旧版本在托盘运行时，安装与卸载都会提示先退出。
- 仍提供免安装 ZIP。

## 投送更可靠

- **投送前会等窗口和按键稳定。** 远控窗口回到前台并稳定 0.1 秒、修饰键松开后再粘贴，最多多等 1.5 秒；不再到点检查一次就放弃。诊断写明停在哪一道检查。
- **切回远端绕过前台锁。** 目标已在前台不再激活；激活结果不再作为失败条件。
- **远端不再反复贴出旧内容。** 同步速度改为快速 180 ms / 标准 0.5 秒 / 兼容 1.2 秒，久未使用后的第一条至少 0.8 秒；听写文字默认留在剪贴板，远端没出现时可直接手动粘贴（可改回恢复原剪贴板）。0.2.0 的速度设置自动迁移。
- **远控回写剪贴板时自动重写。** 内容相同继续；不同内容且你没有键鼠操作时重新写入一次；你自己复制的内容不会被覆盖。
- **再投送随时可用。** 上一条仍占用剪贴板时也能立即重投；核对后投送与再投送走同一路径。
- **快速连按不再丢键。** 上一条还在粘贴时按语音键，粘贴完成后自动开始。
- **取消只影响本轮。** 豆包录音结束后浮条自动关闭，之前排队的文字继续投送；队列上限提到三条。
- **按了没说话** 2.5 秒后提示并交还焦点。

## 新的交互

- **胶囊浮条**：一行显示状态、实时文字和“右 Ctrl 结束”；长文与豆包的整句组字向上增高至 8 行，始终在可见宽度内换行。
- **核对卡片**：右 Ctrl 投送，不再需要勾选确认；被拒时显示原因。
- **底部提示**：已投送 / 再贴一次、上一条正在投送、没有识别到文字、没有找到远程窗口、本次未投送，不抢焦点。
- **准备清单**替代四步引导；**试一次**在真实远端按语音键投送测试文字，没出现时按现象一键调整后重测，结果按 UU 设备保存。
- **托盘与设置精简**：托盘图标区分五种状态，菜单含最近文字的复制 / 再投送 / 打开核对；设置合并为通用、远程客户端、运行环境与诊断三页。
- 界面字体改为微软雅黑 UI，中文显示清晰。

| 文件 | 用途 |
| --- | --- |
| `RemoteVoiceIME-0.3.0-win-x64-setup.exe` | 安装程序（推荐） |
| `RemoteVoiceIME-0.3.0-win-x64.zip` | 免安装版 |

Get-FileHash .\RemoteVoiceIME-0.3.0-win-x64-setup.exe -Algorithm SHA256

## 已知限制

- 投送没有远端回执：“已投送”表示本机已发出粘贴键。
- 与豆包共用右 Ctrl 时不提供“长按重贴”：按下瞬间必须决定是否交给豆包，长按也会切换豆包录音；请用提示或托盘菜单再投送。
- 上一条发送中按下的语音键不交给豆包，自动打开浮条后需再按一次开始录音。
- 豆包录音条与组字行为基于豆包 v0.9.2.7 实测，豆包升级后需重测。
- 本工具不录音、不联网、不落盘保存正文；最近文字仅在内存保留 5 条 / 5 分钟，退出即清空。
